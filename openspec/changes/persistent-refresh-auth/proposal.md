## Why

Текущая cookie-сессия истекает через семь дней без продления. После долгого оффлайна первый 401 сбрасывает пользователя и удаляет загруженные песни и файлы, заставляя повторно входить и загружать библиотеку.

## What Changes

- Короткий access token (15 минут) и долгий refresh token (90 дней без успешного обновления) собственной авторизации в HttpOnly cookies. Успешный refresh продлевает срок на следующие 90 дней.
- Автоматическое обновление с ротацией refresh, серверным отзывом и проверкой Origin/CSRF; без повторного Telegram-входа, пока refresh действителен.
- Вся клиентская логика сессии, refresh, конкурентных запросов и повторов в одном composable `useAuthSession`. Stores и API-сервисы используют его публичный интерфейс.
- Один refresh для параллельных запросов; координация вкладок; максимум один повтор исходного запроса после подтверждённого 401.
- Истечение сессии сохраняет приватный кэш. Локальное чтение последнего подтверждённого пользователя остаётся доступным; синхронизация и изменения требуют подтверждённой сессии.
- Явный выход, смена пользователя и подтверждённый отзыв доступа сохраняют существующие правила очистки и изоляции.
- Переход существующих семидневных сессий без принудительного массового выхода.

## Capabilities

### New Capabilities

- `persistent-auth-session`: обновляемая собственная авторизация, централизованный клиентский транспорт и сохранение оффлайн-данных при истечении сессии.

### Modified Capabilities

Нет опубликованных main specs. Новые требования заменяют трактовку 401 как немедленного удаления всего кэша в завершённом, но не архивированном `telegram-setlists`; при последующей синхронизации необходимо согласовать `private-offline-cache` и `telegram-authentication` с этим изменением.

Frontend: `src/stores/auth.ts`, новый `src/composables/useAuthSession.ts`, `src/services/sessionTransport.ts`, `src/services/libraryApi.ts`, auth/offline UI и проверки reconnect. Серверная реализация требует отдельного согласованного change в backend root при apply. Telegram OIDC остаётся способом первичного подтверждения личности. Новые библиотеки не требуются.
