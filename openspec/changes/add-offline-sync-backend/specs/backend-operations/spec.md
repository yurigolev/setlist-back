## Purpose

Задаёт воспроизводимую серверную эксплуатацию и резервное копирование единственной библиотеки песен и файлов.

## ADDED Requirements

### Requirement: Воспроизводимое окружение разработки
Система SHALL предоставлять документированный способ локально запустить API, реляционную БД и объектное хранилище с изолированными persistent volumes и применёнными миграциями.

#### Scenario: Чистый локальный запуск
- **WHEN** разработчик выполняет документированную команду запуска на чистом окружении с Docker
- **THEN** API, БД и объектное хранилище становятся доступны, а API сообщает готовность через healthcheck

### Requirement: Явный режим публичного API
Система SHALL предоставлять API без регистрации и входа в первой версии. API SHALL явно документировать, что любой клиент с адресом API может читать и изменять библиотеку. CORS SHALL ограничивать только браузерные обращения с иных origin и SHALL не представляться защитой API. Секреты PostgreSQL и объектного хранилища SHALL храниться вне исходного кода.

#### Scenario: Неверный origin
- **WHEN** браузер с недоверенного origin вызывает API
- **THEN** API не предоставляет ему разрешение CORS, но не обещает защиты от прямого HTTP-запроса

### Requirement: Восстановление библиотеки
Система SHALL документировать создание и проверку резервной копии PostgreSQL и объектных данных, достаточных для восстановления связей песен и файлов.

#### Scenario: Проверка бэкапа
- **WHEN** оператор выполняет документированную процедуру проверки восстановления
- **THEN** он может подтвердить доступность песен и связанных вложений в изолированном окружении
